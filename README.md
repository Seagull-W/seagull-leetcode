# Seagull 本地练习台

面向算法与大模型后训练实习准备的本地练习工具。Python / Rust 双语言算法题，中文背景知识、参考实现、提交历史和复习笔记。无需 npm、数据库服务、付费 API 或网络 CDN。

## 启动

需要 **Python 3.10+**。Rust 题还需已安装 **rustc（建议 Rust 1.70+）**，并加入 PATH；Python 题可独立使用。安装工具链需要联网，安装完成后练习平台可以离线使用。

Windows 双击 `start.cmd`，或在 PowerShell 中运行：

```powershell
python -X utf8 server.py --open
```

浏览器访问 **http://127.0.0.1:8765**。按 Ctrl+C 停止服务。端口占用可使用 `--port 8766`；数据目录可通过 `--data-dir D:\SeagullData` 或 `SEAGULL_DATA_DIR` 设置。默认只监听本机 127.0.0.1；请使用启动时打印的地址。

Linux / macOS：`python3 server.py --open`。Windows 是首版的实际验证环境，其他系统尚未进行界面和编译链实机验证。

## 包含什么

- **63 道算法题**，每道都有 Python / Rust 模板、参考实现、思路、复杂度、常见错误与逐级提示。
- **12 个算法专题**：数组与字符串、哈希、双指针与窗口、二分、栈与队列、链表、树、堆、图与搜索、回溯、贪心、动态规划。
- **14 篇知识说明**，包含学习方法、Rust 入门与从状态语义推导动态规划。
- **10 道后训练开放问答**：SFT、DPO、PPO、GRPO、KL、奖励与评测、数据、NaN、实验和 Agent RL。保存回答与自评，不进行不可靠的开放题自动评分。
- 示例运行、全部测试提交、错误分类、编译器反馈、失败用例、运行超时与调试输出限制。
- 自动保存草稿；Python 与 Rust 分开保存；历史代码恢复、收藏、笔记、掌握程度与复习日期。
- 本机 SQLite 持久化、JSON 完整导出与合并导入；导入前自动备份。

PyTorch 编程题、真实大模型训练、云端同步、多用户账号与在线比赛不在首版范围内。

## 怎样刷题

1. 按左侧专题路径选题，先读背景知识。所有解答统一实现 `solve` 并返回结果。
2. 选择 Python 或 Rust，在编辑器中实现；不读取 stdin、不定义 Rust main。
3. “运行示例”只检查前两个公开用例；“提交代码”检查全部测试，并保存完整代码快照和结果。
4. 逐级看提示，再主动展开参考解答；查看参考解答会留下“已看解答”标记。
5. 在“笔记与复习”自评完成方式，安排复习日期；左侧可以筛选待复习题。

快捷键：`Ctrl+Enter` 提交，`Alt+Enter` 运行示例，`Tab` 插入四个空格；回车自动续接缩进。首版编辑器是原生文本编辑器，支持键盘编辑与撤销，尚未集成代码补全、语法高亮、调试器或多文件项目。

通过状态按语言记录；笔记、自评、收藏与解答查看记录按题目共享。看过解答后不要仅凭通过就标记独立掌握。

链表使用 `nexts` 下标表来表达拓扑，不是把链表题简化成数组倒序。树使用**堆式槽位**（孩子 `2i+1` / `2i+2`，`-1` 空槽），与某些网站紧凑层序输入不同。真实节点结构练习可后续扩展。

## 数据保存与备份

默认数据在 `data/practice.sqlite3`，包含草稿、代码快照、结果、题目版本、UTC 时间、笔记和知识回答。网页按浏览器本地时区显示时间。草稿约 600ms 去抖保存，并以浏览器 localStorage 辅助恢复未同步代码；关闭网页或重启服务不清除数据库。

“备份与恢复”可导出 JSON。导入按提交 ID 去重，草稿与笔记按时间保留较新版本，不清除当前记录；导入之前创建 `data/before-import-*.json`。界面显示最近 100 次当前题目当前语言的运行，导出包含全部记录。单个导入文件限制 20 MB。

**不要删除 data 目录或把它当作程序缓存清理。** 更新程序时保留数据目录；数据库 schema v1 与题目 version 会分别记录。数据库、浏览器缓存和 JSON 备份属于本机个人数据，无加密；数据目录、work 和运行临时文件由 `.gitignore` 排除，不能提交到公开仓库。

## 判题边界

首版用于本人运行自己信任的练习代码，**不是安全沙箱**。代码以当前用户权限执行，可访问本机文件和网络；进程超时与输出限制不能隔离恶意代码。不要改为公开网络服务，也不要运行不信任的投稿代码。若要多用户部署，需要另行实现容器或其他权限隔离。

Rust 每次提交编译一次，最多 30 秒；整组测试最多执行 4 秒；输出最多 256 KB（轮询检测存在小幅超出窗口）。超时会终止执行进程，Windows 同时尝试清理进程树。没有硬性内存限制，执行耗时包含启动与测试驱动开销，不用于跨语言或用户排名。自定义线程/后台子进程不属于练习支持范围。

输出值要求正确的 JSON 类型；整数不等于布尔值。外层结果顺序任意的题采用多重集合比较，仍校验重复数与内部顺序。Rust 仅使用标准库，无第三方 crate；函数必须 `pub fn solve`。

测试包括明确期望的边界案例和固定随机种子的小输入案例。**全部通过不是正确性的数学证明，也不保证达到最优复杂度**。测试公开且失败后显示输入，便于学习；它不是防作弊比赛系统。

## 验证与扩展

```powershell
python -X utf8 -m unittest discover -s tests -v
python -X utf8 tests/verify_references.py --language all
```

`tests/generate_cases.py` 使用独立的小输入穷举或不同算法生成额外用例，并与 Python 参考答案交叉核对。生成结果保存在 `content/extra_cases.json`，运行平台无需动态生成期望答案。

题库位于 `content/catalog.py`，专题与问答位于 `content/lessons.py`。新增题目使用 `add`，保持已有 ID 稳定，修改题目语义或测试应提升 version。新输入/输出类型需扩展 `judge.py` 的类型转换和 JSON 序列化；修改记录结构需显式提供 schema 迁移，当前版本不自动处理未来版本。

所有题面、讲解和代码为此项目编写；没有复制 LeetCode 题面或使用其品牌作为本项目名称。
